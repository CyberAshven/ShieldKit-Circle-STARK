# Cohort PolicyAuthority v1

P is a static, non-authorizing template binding exactly R, K, and F. It stores
no concrete Q/A/B/C/J/D instance, nonce, attempt, authorization, claim, run,
or evidence. `executionAllowed` is false and the runtime boundary has no
entrypoint, exports, modules, or activation capability.

The root fixes the 28-edge causal DAG, structured Q/A/live-F/B/C/J/D policy
templates, five positive private-byte K launch rows, and the 4,608-workload
authority. C is the sole external durable consumer; A is immutable and has no
`consumptionState`; J is authority-free.

All validation is byte/JSON/schema/closure work. It never imports a dependency
module or launches an endpoint, loader, binary, VM, worker, runtime, or build.
The envelope is unsealed until `--seal`; `--check` is read-only.
