Static-only commands (run from the repository root):

  node research-lanes/bch-shielded-pool-design/p2/gate-b/cohort-runtime-binding-v1/generate.mjs --check
  node research-lanes/bch-shielded-pool-design/p2/gate-b/cohort-runtime-binding-v1/validate.mjs
  node --test research-lanes/bch-shielded-pool-design/p2/gate-b/cohort-runtime-binding-v1/tests/*.test.mjs

Freeze reads only reviewed N/E/X bytes and JSON. With no external binding
argument, it uses the hard-pinned independent E gate; an optional binding is
accepted only after strict schema, root, manifest, sums, six-record, and
runtime-closure validation:

  node research-lanes/bch-shielded-pool-design/p2/gate-b/cohort-runtime-binding-v1/generate.mjs --freeze [--endpoint-binding <reviewed-E-binding.json>]

Freeze stages a complete candidate in a same-parent temporary directory and
uses a no-replace fail-closed build-state protocol for the envelope links. A
state record means publication is incomplete; `--check` is read-only and
reports that manual recovery is required. No command launches a runtime
image, endpoint, BCHN, LeanBCH, VM, controller, or authorization flow.
