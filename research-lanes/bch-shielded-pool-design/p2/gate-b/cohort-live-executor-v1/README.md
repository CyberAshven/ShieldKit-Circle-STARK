# cohort-live-executor-v1

This is an additive, non-authorizing, static model. It contains strict schemas, canonical projections, a pure reducer, and adversarial KATs. It contains no endpoint runner, descriptor/claim writer, live-observation brand mint, observation predicate, terminal publisher, commit implementation, or authorization instance. `executionAllowed` is permanently `false`.

Authority is forward-only: a frozen digest-only external A0 binding plus static A1 authenticate the structural B projection; A0/A1/B define the future exclusive C; A0/A1/B/C bind evidence-only J. Static v1 never parses external authorization content. A1 paths are authoritative for C output and claim paths. Snapshot-v1 has closed catalog/source descriptors and retains only the exact `{id:'/proc/self/exe', role:'runtime-executable'}` recovery projection, with `rawSha256`, `byteLength`, an executable-identity digest, and seven-field stat. C inventory is exactly derived from that one-entry B projection and its digest is bound into an approved, non-self-referential join-seed projection. A private branded snapshot adapter is absent: `snapshotAdapterBranded` is `false` and `externalBJoinStatus` is permanently `PENDING_NONAUTHORIZING`. Thus this package models no external B join. J does not bind future journal content; it binds the exact B stdin root and static A1 endpoint schedule instead.

The future journal has Native primary, Libauth primary, BCHN primary, Lean primary, and Lean secondary in that order. Every entry and index record binds J. `endpoint-input-durable` binds the exact full B stdin record. Journal-entry, index, and stream paths share one collision-free namespace. Snapshot descriptor stats are exactly `{dev,ino,mode,uid,gid,nlink,size}` with decimal strings (and octal `mode`); stream stats add `mtimeNs`, contain `nlink`, and require `stat.size == byteLength`. The observation file is a structural requirement projection only. No receipt shape, digest, callback, plain object, or frozen object can be accepted as provenance in v1.

The reducer preserves the exact durable entry prefix in failure/recovery states. B without C remains unclaimed; C without J has exactly a zero-entry recovery prefix. There is no caller-supplied containment or active-external flag. For BCHN and both Lean endpoints, durable `endpoint-started` is a conservative pre-spawn barrier: through durable `stderr-durable` and before durable `endpoint-close-observed`, every `FAIL` or `RECOVER` becomes `RECOVERY_BLOCKED_ACTIVE_EXTERNAL`, even if spawn crashed before occurring. Recovery has no endpoint or observation transition. After exactly 30 entries and five seals, the sole forward state is `SUCCESS_STRUCTURE_READY_PENDING_PRIVATE_OBSERVATION`; static v1 has no observation-sealed, terminal-validation, or success no-replace transition. Success publication always fails closed until a future package supplies a private unforgeable observation brand. Failure/recovery terminals bind their exact durable prefix and suffix selection.

`snapshot-boundary.mjs` copies caller-supplied bytes only to compute scalar SHA-256/length metadata; it never returns a mutable byte view, opens a file, accepts a descriptor number, or retains catalog/source state. Its runtime-executable input is strict structural recovery metadata only. `observation-boundary.mjs` exports only a structural observation requirement; it has no acceptance or minting capability.

The manifest has exactly 21 ordered content files. Each record has a raw SHA-256 plus a domain-separated content digest, `0644` regular-file mode, and link count one. The root `contentDigest` binds the full ordered manifest. `SHA256SUMS` closes over `MANIFEST.json` and all 21 content files. `node generate.mjs --check` is read-only. `node generate.mjs --write` is the sole explicit envelope-refresh mode and never builds or runs an executor.

All test inputs are structural fixtures only. They are not A0/A1 authorization, claims, live execution, observation evidence, runtime bindings, or release material. External A1/runtime and snapshot/catalog pins remain pending and intentionally unasserted by this static package.
