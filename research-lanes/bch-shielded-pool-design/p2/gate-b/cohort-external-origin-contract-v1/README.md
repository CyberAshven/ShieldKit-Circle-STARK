# Cohort external-origin contract v1

Status: `static-external-origin-contract-catalog-no-instances-non-authorizing-origins-unavailable-unqualified`.

This package is a static, data-only contract catalog. It authenticates pinned static upstream bytes and type relationships only. It creates no instance, owner identity, capability, root value, private byte, projection material, admission, guard lift, authority, runtime, writer, generator, binder, reducer, or endpoint surface.

The CABM 17-node, 22-edge authority prefix is retained exactly. A separate 14-node, 14-edge overlay records only unavailable-origin and variant-specific prerequisites. Static dependency edges never satisfy an overlay predecessor.

`RETRY_PREDECESSOR`, `LIVE_F_CAPTURE`, and `WORKER_ROWS_ROOT` are unavailable external origins. Their prospective value-bearing names occur only in ordered `futurePreimageKeys`; no unavailable value is represented by `null` or a placeholder. Every grant and admission flag is false. Retry remains blocked, and D remains never admitted and blocked.

The contract fixes five endpoint-control aliases and 4,608 workloads per endpoint while retaining K's 1..4,096 worker-row bounds. These quantities have no equality, ratio, batching, or one-workload-per-row meaning. Projection ordering, encoding, roots, and bytes remain unavailable external material.

`validate-static.mjs` is read-only and build-time-only. It verifies canonical JSON/LF, closed schemas, exact semantic catalogs, all 29 pinned upstream regular-file leaves, safe containment/no symlinks/nlink=1, closure shape, and—once sealed—the manifest and checksums. It never imports an upstream runtime module or evaluates an upstream package.

The package cannot authenticate a jointly substituted validator and envelope. Any future integration must independently pin the validator, root, manifest, and checksum bytes before relying on its local static checks.
