node generate.mjs --materialize
node generate.mjs --check
node validate.mjs
node --test reproducibility.test.mjs mutation.test.mjs

`--materialize` is the sole explicit byte-copy/materialization mode. It reads
the pinned Node 22.23.1 and host ELF inputs, parses them without execution,
and seals the package. `--check`, `validate.mjs`, and the tests are
read-only/subprocess-free and never invoke Node from `image/root`, the loader,
readelf, ldd, a compiler, package manager, controller, engine, VM, or
authorization path.
