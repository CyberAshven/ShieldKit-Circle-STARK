Unsealed CLI and test usage:

  node validate-static.mjs --mode unsealed
  node --test test/static.test.mjs test/source-resolution.test.mjs test/package-boundary.test.mjs test/mutation.test.mjs

Sealed CLI and test usage requires the external caller to supply all four review-anchor literals; this file intentionally provides no default or future hash:

  : "${SSA_REVIEW_ANCHOR_ROOT:?caller must supply an absolute external anchor root}"
  : "${SSA_REVIEW_ANCHOR_LOCATOR:?caller must supply the external anchor locator}"
  : "${SSA_REVIEW_ANCHOR_BYTES:?caller must supply the external anchor byte count}"
  : "${SSA_REVIEW_ANCHOR_RAW_SHA256:?caller must supply the externally pinned anchor SHA-256}"
  export SSA_REVIEW_ANCHOR_ROOT SSA_REVIEW_ANCHOR_LOCATOR SSA_REVIEW_ANCHOR_BYTES SSA_REVIEW_ANCHOR_RAW_SHA256
  node validate-static.mjs --mode sealed \
    --review-anchor-root "$SSA_REVIEW_ANCHOR_ROOT" \
    --review-anchor-locator "$SSA_REVIEW_ANCHOR_LOCATOR" \
    --review-anchor-bytes "$SSA_REVIEW_ANCHOR_BYTES" \
    --review-anchor-raw-sha256 "$SSA_REVIEW_ANCHOR_RAW_SHA256"
  node --test test/static.test.mjs test/source-resolution.test.mjs test/package-boundary.test.mjs test/mutation.test.mjs

The authored closure is always 24 files. Paired MANIFEST.json and SHA256SUMS distinguish an exact 26-file sealed package closure from the 24-file unsealed form; the sealed sibling review anchor is outside both closures. Determine the on-disk lifecycle state from that pair, not from this prose.

Before any later import or CLI invocation, the external caller or lane must independently raw-pin and SHA-256-check validate-static.mjs; the local validator cannot authenticate its own evaluating bytes. Sealed use additionally requires an independent raw pin for the sibling review anchor outside the package. Neither the validator nor the anchor self-certifies these pins.

These are validation and test usage forms, not authorization. No invocation creates authority, instances, runtime state, results, evidence, qualification, ranking, selection, admission, execution, sealing permission, lane integration, or Gate B1.
